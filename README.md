# Extension Hub — Ziro Edition

A shell-based server and panel management toolkit.

**Version: 1.0**  
**Edition: Ziro Edition**

## Run

```bash
chmod +x menu/UI.sh
sudo bash menu/UI.sh
```

## Main menu

- Panel Manager
- Wings Manager
- Toolbox
- Themes
- System Tools
- Container Tools
- New Module
- Extras

The VPS menu option has been removed from the main menu.

## Note

Some modules still fetch their installer scripts from the original upstream GitHub repositories.
Before publishing your own fork, update those raw GitHub URLs to your Extension Hub repository.

## Before using your GitHub-hosted modules

Search the project for `YOUR_GITHUB_USERNAME` and replace it with your GitHub username after uploading this repository. The original upstream URLs have been converted to placeholders so this fork does not continue identifying itself as the original project. Until those URLs are updated, remote modules will not download.
